# Model Card: EarlyCare AI

## Current model status
No machine-learning model is enabled in this version.

## Intended use
Educational demonstration of a health-screening workflow and safety-first application architecture.

## Out-of-scope use
Clinical diagnosis, treatment decisions, emergency triage replacement, or claims of calibrated individual disease probability.

## Current assessment logic
A limited rule-based warning-sign screen checks selected symptoms such as chest pain, difficulty breathing, new confusion, fainting, and severe bleeding. The rule set is intentionally conservative but incomplete.
